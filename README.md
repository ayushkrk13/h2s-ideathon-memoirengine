## About The Project

**MemoirEngine** is a living family archive. It uses advanced voice AI to capture, preserve, and pass on the stories of the people you love. Some stories only exist in someone's voice, and MemoirEngine is designed to ensure those stories are never lost.

By transforming conversations into an interactive, visually stunning archive—complete with a 3D memory tree, interactive timelines, and beautiful typographic chapters—we allow families to explore their history and legacy in a way that feels organic and alive.

## Features

- **Voice to Legacy:** Transform spoken stories into beautifully written biographical chapters.
- **Living Memory Tree:** An interactive 3D particle tree that grows and represents your family's connections.
- **Interactive Archive:** Explore memories through photo walls, timelines, and immersive story graphs.
- **Privacy First:** Your family's legacy is kept safe, secure, and entirely under your control.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Built With

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Three.js](https://threejs.org/) & React Three Fiber (for the 3D memory tree)
- [Tailwind CSS](https://tailwindcss.com/)
- [GSAP](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/) (for fluid animations)
